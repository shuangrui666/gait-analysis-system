# AI 协作档案

## 目的
记录 AI 在项目中的辅助工作，保证提示词、输出、人工核验、采纳情况和最终决策之间可追溯。

## 工具登记
见 [AI 工具登记表](ai_tools_registry.md)。

## 建议归档结构
后续可按日期或任务建立记录，例如：
- `YYYY-MM-DD_data_audit.md`
- `YYYY-MM-DD_python_analysis.md`
- `YYYY-MM-DD_report_review.md`

## 每次协作记录
- 日期与任务目标；
- 工具名称及可获取的模型/版本信息；
- 用户提示词和可保存的 AI 回复；
- AI 输出涉及的文件、数据或结论；
- 人工核验方法与结果；
- 采纳、修改或拒绝情况及理由；
- 相关 Git commit、数据集 ID 和证据路径。

## 真实性规则
- 只归档实际发生且可获得的对话内容。
- 无法恢复的历史对话应标记为“未归档/无法获取”，不得补写成逐字记录。
- AI 生成的事实、代码和分析必须人工验证。
- 不上传密码、访问令牌、个人敏感信息或无关隐私。
- AI 建议不等于实验事实或最终决策。
