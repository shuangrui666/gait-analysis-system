# 快跑、上楼、下楼原始数据深度审计与三轴波形分析

- 审计对象：17组唯一动作原始ZIP（快跑7、上楼4、下楼6）
- 数据源：原始ZIP内 `Raw Data.csv`、`meta/time.csv`；原始文件只读。
- SHA-256：与 `data/metadata/dataset_sha256_mapping.csv` 逐组核对，17/17一致。
- 指标口径参照静止组：采样间隔中位数、估算频率、间隔偏差计数、三轴均值/样本标准差/最小值/最大值/P05/P95、加速度模长统计。
- 采样偏差筛查阈值：相对中位间隔偏差>5%及>20%；仅为审计标记，不作为自动剔除标准。

## 4. 结果解释与审计结论

- 快跑裤袋Total 500Hz四组的三轴波动明显高于上楼/下楼裤袋Total 500Hz组；但组间动作速度、手机在裤袋中的实际运动和起止边界仍可能影响结果。
- 快跑手持组的轴向波动更大，提示手持摆动/手臂动作是明显混杂因素，不应与裤袋数据合并。
- 上楼四组与下楼五组均为裤袋Total约500Hz，具备较一致的设备与放置分层；当前仅作描述性比较。
- 下楼长时组 GAIT-98BDF65C41C4 约32.634s，用户此前说明开始后放入、结束前取出；应保留边界风险，不能整段直接解释为连续下楼。
- 快跑裤袋组存在手机放入/取出边界风险。波形可帮助定位突变，但不能单凭曲线确认具体动作事件。
- 三轴SD反映整段轴向离散程度，可能同时受动作、手机朝向、手持摆动、裤袋内移动及操作边界影响。不能仅凭SD决定动作标签或正式纳入状态。
- 本轮不伪造稳定区间，不对原始CSV自动裁剪；视频逐组映射、精确动作稳定区间和独立动作速度测量仍保留为局限。
