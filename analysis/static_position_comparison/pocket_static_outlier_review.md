# 裤袋静止③异常波动复核报告

## 1. 复核对象与问题

- 数据集：`GAIT-2DB4E6C4072D`
- 原始文件：`站立放口袋，电脑控制.zip`
- SHA256：`2db4e6c4072d4eea635a469db33322d01202bbb2854296e947c8c239245119b0`
- 用户已确认的实验条件：手机放在左裤袋，站立不动。
- 原始数据：11,205 行，记录时长约 22.408 秒，含重力总加速度，采样频率约 500 Hz。
- 复核目的：判断异常波动是否贯穿全程，是否存在可辨识的稳定区间，以及该数据能否进入后续静止状态分析。

## 2. 数据与采样检查

原始 ZIP 可正常读取，内部包含 `Raw Data.csv`、`meta/device.csv` 和 `meta/time.csv`。CSV 五列完整，时间戳递增，采样间隔中位数约 0.002 秒，对应约 500 Hz。

`meta/time.csv` 记录开始时间为 2026-10-28 18:36:21.450（UTC+08:00），结束事件约在 18:36:43.884。原始 CSV 的首末时间戳约为 0.0181 秒和 22.4261 秒。

传感器字段为加速度计（accelerometer），本组导出字段为三轴加速度及其模长，属于含重力的总加速度数据。

## 3. 三轴波形复核

对本组与另外两组左裤袋静止数据进行同尺度时域对照后，观察到：

1. 裤袋③的明显大幅波动主要集中在记录开始后的约 0–3 秒。
2. 约 3 秒后，X、Y、Z 三轴迅速进入相对稳定的平台区，后续没有观察到与开头同等级别、持续性的剧烈波动。
3. 另外两组裤袋静止数据没有出现同等幅度的开头波动；这说明裤袋③的全程统计量被开头短时波动显著抬高。
4. 仅凭加速度曲线不能确认波动的具体原因。可能涉及采集开始阶段的手机/身体微动、手机在口袋中的位置调整或其他短时扰动，但现有记录不足以在这些原因之间作出判断。

因此，本次将 0–3 秒标记为疑似过渡/扰动区间，而不是断言其一定由“放入手机”造成。

裤袋③全程的三轴标准差明显高于另外两组；但截取 3 秒之后的区间后，三轴标准差与模长标准差均降至与另外两组相近或更低的水平。这支持“异常主要局限于开头短时区间”的判断。

## 5. 纳入决定

| 对象 | 状态 | 决定 |
|---|---|---|
| 原始完整记录（0–22.426秒） | `pending_verification` | 不将完整区间直接用于静止特征统计；原始文件永久保留作审计证据 |
| 开头区间（约0–3秒） | `excluded` | 从静止状态特征计算中排除，标记为疑似过渡/扰动段 |
| 稳定区间（3.000秒起至记录结束） | `selected` | 可作为裤袋静止③的有效候选片段，进入后续指定分析；必须保留截取起止时间和原始文件 SHA256 |

**最终判断：不建议把裤袋③整段数据直接纳入分析；建议仅纳入 3.000 秒起的稳定片段。** 该决定是“片段级纳入”，不是对原始整份 ZIP 的无条件合格认证。

## 6. 复现与数据管理

- 原始 ZIP 不作修改，不覆盖、不删除。
- 建议后续分析通过原始文件 SHA256 定位来源，并按 `Time (s) >= 3.0` 截取稳定片段。
- 截取片段保留原始五列，不做平滑、滤波或重采样。
- 若后续发现实验视频或操作日志能确定开头扰动的真实原因，应补充证据并更新本报告；在此之前不对原因作确定性归因。
- 本次复核统计指标已提交为同目录的 `static_pocket_signal_review_metrics.csv`。三组裤袋静止数据的三轴时域对比图已归档为 [`static_pocket_three_dataset_review.svg`](./figures/static_pocket_three_dataset_review.svg)，可直接查看各组 X、Y、Z 轴波形。图中展示原始时间序列及裤袋③开头约 3 秒的短时波动与后续相对稳定区间。

## 7. 限制

本次结论基于原始 CSV、ZIP 元数据、用户已确认的“左裤袋、站立不动”条件，以及三组静止数据的波形和统计量对照。当前没有可用于精确定位开头扰动成因的视频时间标记或逐秒操作日志。因此，3 秒作为保守的稳定区间起点，是依据波形进入平台区的可重复观察作出的数据处理决定，不代表已查明扰动发生的物理原因。
