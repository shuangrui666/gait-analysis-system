## 6. 传感器类型判断

四组 CSV 使用 `Acceleration x/y/z` 与 `Absolute acceleration` 字段，而不是 `Linear Acceleration x/y/z` 字段；结合静止时加速度模长约为重力加速度量级，可判定本次分析对象为**含重力的总加速度（total acceleration）**。

注意：设备元数据同时列出加速度计和线性加速度传感器能力；本次类型判断依据实际导出的 CSV 字段，不是仅凭设备支持的传感器列表推断。
