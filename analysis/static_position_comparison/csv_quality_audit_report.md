# CSV 数据质量审计报告

## 1. 审计目的

本报告对课题八《多姿态步姿态加速度特征采集与对比》中的四组静止状态加速度原始数据进行 CSV 质量审计。

本次审计主要确认：

1. ZIP 文件能否正常读取，内部是否包含预期数据文件。
2. CSV 字段是否完整、统一。
3. 是否存在空值、完全重复行。
4. 时间戳是否严格递增。
5. 三轴加速度与加速度模长是否一致。
6. 数据结构是否满足后续采样稳定性和时域波形分析的基本要求。

本报告只评价数据文件及其数值结构，不直接判定实验操作是否完全符合要求。

模长一致性采用以下公式复核：

\[
a=\sqrt{a_x^2+a_y^2+a_z^2}
\]

四组数据中，CSV 模长列与根据三轴重新计算的模长之间最大绝对误差均小于 \(10^{-8}\ \mathrm{m/s^2}\)。

因此，模长列在数值计算层面与三轴数据一致。

## 6. 审计结论

四组 CSV 均通过本次基础结构审计：

- 文件可以正常读取。
- 字段完整且统一。
- 未发现空值。
- 未发现完全重复行。
- 时间戳严格递增。
- 加速度模长与三轴计算结果一致。

**审计结论：基础 CSV 结构检查通过。**

需要强调：

基础结构通过不代表实验数据不存在物理异常，也不代表手机放置方式、实验姿态和采集过程完全一致。

因此，四组数据仍需结合采样间隔、三轴时域波形和实验记录进行进一步评价。
