# 11组走路数据逐组审核记录（第一轮证据审查）

- 审核日期：2026-11-03
- 审核范围：39组数据清单中的11组 walking 记录
- 审核性质：第一轮逐组证据审查；不是最终纳入判定
- 状态口径：仅使用 `selected`、`excluded`、`pending_verification`
- 时间口径：下表时间均为 Phyphox 记录时间（秒），目视候选时间为粗定位，不是精确切片边界。

## 1. 审核证据与限制

本轮综合使用仓库中已有的：
- `walking_segment_review.csv`：逐组目视候选区间与波形观察；
- `walking_stable_interval_screening.md/csv`：统一参数的自动候选区间；
- `RAW_DATA_VERIFICATION.md`：原始 ZIP/CSV 复核范围；
- `VIDEO_EVIDENCE_REVIEW.md`：视频证据候选分组与关联限制；
- `walking_waveform_review.md`、`walking_review_log.md`：此前的逐组观察与实验条件记录。

**原始数据复核边界：**目前只有 `GAIT-A8B03FC23EA3` 和 `GAIT-4F5177C0E51D` 两组原始 ZIP 在本轮可追溯记录中被实际打开并复算。其余9组有清单、波形审核和筛查记录，但本轮没有再次从原始 ZIP 打开 CSV。因此不得声称其行数、缺失值、精确采样间隔、设备元数据和极值位置已经完成原始级复核。

**视频证据边界：**现有视频审核只建立了动作/放置方式层面的候选组关联。7个走路视频证据条目与具体 ZIP 的一对一映射仍为 `unlinked_insufficient_unique_evidence`；视频未与传感器时间轴同步。因此本轮不能用视频确认任何一组的精确起步、放入口袋、取出或停止时刻。

## 2. 逐组审核结论

### 2.1 GAIT-1A988B796ED4

- **实验条件：**手持；Total（含重力）；名义采样率约500 Hz。用户此前确认是正常速度行走，文件名中的“慢走”不作为速度判据；实际步速没有量化。
- **发现的问题：**波形审核记录显示记录前段和末段存在非稳定变化，中间有周期性步行样波动。
- **问题时间：**约0–1.5 s、约15.5 s之后；属于波形目视粗定位。
- **可考虑使用的区间：**约1.5–15.5 s，作为候选区间，不代表已确认连续步行。
- **视频证据：**手持走路视频候选组包括 EV-012、EV-024、EV-029，但没有唯一对应到本 Dataset ID 的证据。
- **当前结论：**`pending_verification`。可作为手持正常速度探索候选；不能作为已确认的正式主样本。
- **下一步：**重新打开原始 ZIP/CSV，核验时间戳、三轴和极值；查找唯一试验标识或同步时间证据。

### 2.2 GAIT-642C922009F2

- **实验条件：**手持；Total；约500 Hz。用户此前确认正常速度，实际步速未量化。
- **发现的问题：**起始和结束阶段存在姿态/静止变化；基础质量审计提示极端值比例偏高。此前特别提出约23 s附近峰值需要重点检查。
- **问题时间：**约0–3.5 s、约24.5 s之后；另将约23 s附近列为重点异常复核点。现有记录没有提供该峰值的精确时间戳、轴向、幅值及其是否为真实动作冲击。
- **可考虑使用的区间：**约3.5–24.5 s为目视候选区间，但由于异常点靠近候选区间末端，不能直接整段纳入。
- **视频证据：**手持走路视频候选组有记录，但无法唯一关联本组，也不能确认23 s附近发生了什么。
- **当前结论：**`pending_verification`。异常比例提示需要复核，不构成整组排除理由。
- **下一步：**必须从原始 CSV 定位约23 s峰值，检查 X/Y/Z、合成模长、相邻采样点、是否削顶/突跳及该峰值前后周期是否连续；再决定只排除异常片段还是整组不适用。

### 2.3 GAIT-2FA81A7DC0BB

- **实验条件：**左裤袋；Total；约500 Hz。实验记录提示开始后放入手机、结束前取出。
- **发现的问题：**周期性波动明显，但起始放入和结束取出可能污染边界。
- **问题时间：**起始边界约0–1.5 s、结束边界约19.5 s以后为待核区域；这些时间只是候选定位，不是已证实的放入/取出时刻。
- **可考虑使用的区间：**约1.5–19.5 s。
- **视频证据：**属于左裤袋走路视频候选组；无法唯一映射到某段视频。
- **当前结论：**`pending_verification`。保留原始记录；候选中段可继续检查。
- **下一步：**对照原始 CSV 检查开头姿态突变、末尾取出动作影响，并寻找可同步的过程证据。

### 2.4 GAIT-387D48DED7C0

- **发现的问题：**它与其余500 Hz Total 数据不是同一传感器输出，不能直接合并计算或比较原始幅值；现有波形目视记录提示前后边界可能存在非稳定段。
- **问题时间：**约0–1 s及约21 s之后为粗略边界范围。

- **当前结论：**`pending_verification`。可保留为独立辅助数据，不并入500 Hz Total 主比较。
- **下一步：**打开原始 ZIP 核验真实列名、采样率和时间戳；以 Linear 专属参数单独分析，并重新核对动作速度标签。

### 2.6 GAIT-4F5177C0E51D

- **实验条件：**左裤袋；Total；约500 Hz。原始 ZIP 已实际打开复核。
- **原始数据核验：**17,283行；CSV 时间跨度34.564 s；中位采样间隔0.002 s（约500 Hz）；本轮已核验 X/Y/Z 数值列存在，未发现缺失数值行。合成模长均值10.9591 m/s²、标准差3.9796 m/s²、最小1.6959、最大30.9411 m/s²。

- **可考虑使用的区间：**约3.5–31.0 s可作为优先复核的信号层候选段；需再检查起始段是否有可用步行信号及末端变化。

- **当前结论：**`pending_verification`。原始 CSV 结构和采样情况已核验，但稳定行走边界和视频关系未确认。
- **下一步：**按原始 CSV 重新检查3.5 s之前和31 s之后的三轴/模长曲线；不要仅凭全段标准差判定数据质量。

- **下一步：**优先核对9.5–11.5 s低动态区和20 s之后的变化；若没有视频/日志，只能报告为信号变化，不能给出动作原因。
