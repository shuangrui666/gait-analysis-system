# 走路组稳定行走区间信号筛查（阶段性）

## 目的与边界
本报告对11组去重后的原始CSV进行统一信号层筛查。自动筛查结果仅是候选区间，不等同于人工确认的稳定行走区间，也不自动决定整组数据纳入。所有数据集状态暂保留 `pending_verification`。

## 方法
- Total 与 Linear 分开处理，不混合比较。
- 对各自三轴信号分别进行四阶 Butterworth 0.5 Hz 高通滤波，再计算动态三轴合成模长。
- 采用2.0秒窗口、0.25秒步进。
- 每窗计算动态模长 RMS；计算0.35–1.20秒滞后范围内的最大归一化自相关，作为周期性线索。
- 启发式筛查条件：窗口RMS不低于该组窗口RMS的第30百分位，且最大自相关不低于0.15；允许填补单个窗口间隙，仅报告持续至少2秒的连续片段。
- 这些阈值是用于定位复核片段的工程筛查规则，不是经过验证的步态分类器或统计显著性阈值。

## 解读限制与下一步
1. 高通动态强度和自相关只能说明信号存在持续变化及重复性线索，不能单独证明受试者连续行走。
2. 手机放入/取出、手持姿态改变、裤袋内手机转动、停步和环境振动均可能形成类似信号。
3. 对已知有放入/取出风险的数据集，应结合原始波形与实验记录保留边界不确定性；视频若未拍到实际行走，不得用来确认步行区间。
4. `GAIT-387D48DED7C0` 为100 Hz Linear，独立分析，不与500 Hz Total汇总比较。
5. `GAIT-06C3EF47B18A` 有手持姿态变化，不能作为固定手持姿态主对照。
6. `GAIT-642C922009F2` 的极端值需检查发生时刻及其是否落在候选区间内；不能仅凭全段极值决定排除。
7. 本轮所有11组均维持 `pending_verification`。在完成视频/实验日志关联、边界人工确认及异常点定位前，不标记 `selected`。
