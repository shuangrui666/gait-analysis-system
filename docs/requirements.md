# 项目任务要求

## 1. 项目任务
围绕“多姿态步态加速度特征采集与对比”，采集并整理不同动作状态的手机加速度数据，开展数据质量审核、预处理、特征提取、可视化和比较分析。

## 2. 功能性要求
- 保存 Phyphox 导出的原始数据，不覆盖原文件。
- 为数据文件分配唯一数据集 ID。
- 登记动作类别、设备、传感器类型、放置方式、采集日期、采样信息及来源；未知字段明确标为待核实。
- 建立数据质量审核和纳入/排除决策记录。
- 将原始数据、处理结果、代码、参数和图表关联。
- 对不同动作条件进行可解释的特征比较。
- 形成包含方法、结果、局限性和复现说明的报告。

## 3. 非功能性要求
- 可追溯：文件、处理步骤和结论有来源。
- 可复现：记录运行环境、参数和执行方法。
- 数据完整性：保留原始文件及 SHA-256 校验值。
- 透明性：记录失败尝试、方案变更和未解决问题。
- 诚实性：不补造采集条件、视频、时间戳或实验结果。

## 4. 分析前置条件
正式分析前必须明确：
1. 每个文件对应的动作和放置方式。
2. 传感器测量类型（例如含重力的总加速度或去重力线性加速度）。
3. 时间列、单位、采样率及缺失值情况。
4. 重复文件、异常文件和无法确认文件的处理方式。
5. 最终纳入数据集及其审核依据。

## 5. 验收标准
- 清单中的文件与仓库实际文件可逐一对应。
- 哈希校验可复算且匹配。
- 每条正式分析数据均有可解释的纳入状态。
- 预处理代码可从原始数据重新生成处理结果。
- 特征定义、单位、参数和图表生成方法明确。
- 报告中的结论能够追溯到数据和代码。
