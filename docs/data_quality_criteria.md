# 数据质量标准（工作稿）

> 本标准为拟采用的审核框架，阈值和最终规则尚待根据真实数据格式及课程要求确认。未确认前不应把它描述为已完成的正式验收标准。

## 1. 文件完整性
- 文件可读取，格式与扩展名一致。
- 文件非空，具有预期列和有效记录。
- 原始文件 SHA-256 可复算并与映射表一致。

## 2. 结构与单位
- 时间列可解析，单位明确。
- 加速度轴列存在且为数值。
- 单位明确（例如 m/s²）；不同单位不得直接比较。
- 传感器类型及重力处理方式有来源依据。

## 3. 时间序列质量
- 检查时间戳重复、倒序、缺口和采样间隔变化。
- 检查记录中断、异常短记录和非数值记录。
- 采样率以数据时间戳计算并与设置记录交叉核验。

## 4. 实验条件
- 动作类别、放置位置、手机方向和重复编号有记录。
- 采集条件不明的文件标记为待核验。
- 操作启停或手机放入/取出产生的干扰需识别并记录。

## 5. 异常值
异常值先标记和调查，不自动删除。需区分真实动作峰值、设备操作冲击、传感器错误和解析错误。任何剔除均须记录规则、数据集 ID 和影响。

## 6. 纳入状态
每个数据集最终状态应明确为纳入、排除或待定，并记录理由、审核人/来源、日期和证据链接。当前审核表中 not_final 状态不得视为已通过。

## 7. 分析前验收门槛
- 原始文件与清单对应；
- 哈希校验通过或差异已解释；
- 传感器、单位、动作和放置标签达到分析所需可信度；
- 采样时间序列通过结构检查；
- 最终纳入决定已记录；
- 处理规则和排除规则已版本化。

## 8. 待定阈值
采样率容差、最短记录时长、缺失比例、异常值判定阈值等需要基于实际数据分布和实验方案确定。本文件暂不虚构数值阈值。
