# 数据采集规范（工作稿）

> 当前版本为待核实工作稿。不得将其视为所有历史数据的真实采集记录。正式执行前应确认具体 Phyphox 配置并在实验日志中记录。

## 1. 采集前检查
- 确认手机型号、系统版本及 Phyphox 版本。
- 确认所选传感器名称、输出字段、单位和是否含重力。
- 确认采样率/采样间隔、记录时长和导出格式。
- 检查存储空间、电量及设备固定方式。
- 为每次采集分配实验编号，并准备同步记录。

## 2. 手机放置
正式采集应为每类动作规定统一的放置位置、方向和固定方式。当前计划以裤袋放置为统一方案时，需进一步明确具体口袋、手机屏幕朝向和手机长轴方向。历史手持、桌面或其他放置方式必须如实标记，不得混入同一受控组而不作说明。

## 3. 动作执行
每次采集记录动作类别、开始/结束时间、重复编号、环境、操作异常及备注。动作速度应按方案定义；“正常速度”等描述需尽可能补充可执行的操作说明。

## 4. 启停与操作干扰
记录启动、放入手机、开始动作、停止记录的顺序。若启动后放入裤袋造成额外运动，应标记该段可能的操作干扰，并在分析时决定是否截除。不得把设备操作产生的加速度误认为目标动作信号。

## 5. 导出与命名
保留 Phyphox 原始导出文件。建议文件名使用稳定编号和已确认的元信息；原始文件名也必须登记，不得只保留重命名后的名称。

## 6. 每次采集必须记录
- Experiment ID / Dataset ID
- 日期与时间（以设备实际记录为准）
- 动作类别与重复编号
- 手机型号、Phyphox 版本
- 传感器类型、单位、采样信息
- 手机放置位置、方向和固定方式
- 采集时长及启停操作顺序
- 视频/照片证据编号（若有）
- 异常、偏差和待核验事项

## 7. 历史数据
历史数据不符合当前统一规范时，保留原始记录并标注差异。不能通过事后修改元数据使历史采集看起来符合新规范。

## 8. 版本状态
本文件是工作稿。正式采集前应在 `experiment/protocol_changes.md` 记录批准日期、变更内容和适用范围。
