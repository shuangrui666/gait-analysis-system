# 项目概述

## 项目名称
Gait Analysis System（步态加速度特征采集与对比）

## 课程课题
课题 08：多姿态步态加速度特征采集与对比。

## 项目目的
基于手机惯性传感器采集不同运动状态下的加速度数据，整理实验数据与采集元信息，建立可追溯的数据处理流程，并比较不同动作条件下的加速度特征。

## 当前状态
当前仓库处于**历史数据整理、数据治理与实验审查阶段**。已有原始数据登记、哈希映射、审核标记、数据字典、实验过程记录和证据索引。39 组数据的最终纳入状态尚未全部确定；不能将当前数据清单视为已验收的正式分析集。

## 研究对象与条件
项目关注的动作类别、手机放置位置、传感器类型、采样设置及实验时长，应以每次实验的原始记录为准。历史数据存在采集条件差异，分析时必须保留这些差异，不得在缺少证据时推断或补写。

## 工作流程
1. 明确任务要求与实验设计。
2. 采集并保留原始数据。
3. 登记数据文件及采集元信息。
4. 审核数据质量与证据关联。
5. 确定正式分析数据集。
6. 实施可复现的数据预处理。
7. 提取定义明确的加速度特征。
8. 可视化并比较动作条件。
9. 评估结果、局限性与可重复性。
10. 编写实验报告。

## 科学与工程原则
- 原始数据只读保存，不以处理结果覆盖原始文件。
- 每份数据使用稳定 ID，并关联原始文件名与 SHA-256。
- 区分事实、推断、待核验事项和最终决定。
- 数据排除或纳入必须记录理由与证据。
- AI 输出必须人工核验，不直接作为实验事实。
- 处理代码、参数、环境与结果应能够追溯。

## 目录导航
- `data/raw/`：原始数据
- `data/metadata/`：数据登记、字典、审核标记及哈希映射
- `experiment/`：实验日志、迭代、故障和方案变更
- `evidence/`：实验过程证据及索引
- `docs/audit/`：数据审核与审计记录
- `ai_collaboration/`：AI 协作记录
- `docs/`：项目设计与最终报告
